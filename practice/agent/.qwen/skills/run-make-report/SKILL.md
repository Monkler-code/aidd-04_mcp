# Навык: Генерация xlsx отчётов 

## Входные данные
Файл make_report.py в директории .qwen/skills

## Как запустить скрипт
Введи команду в терминале
```bash
python3 .qwen/skills/make_report.py
```

## Куда сохраняется файл 
Файл сохраняется в директорию .qwen/skills

## Как проверить результат
1. Убедись, что код возврата программы равен 0.
2. Проверь, появился ли файл в директории /qwen/skills.
