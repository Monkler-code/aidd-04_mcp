# AGENT: make_report — отчёт о задачах в .xlsx

## Задача
Написать тесты к скрипту `make_report.py`, который создаёт таблицу xlsx на два листа: со всеми задачами и недельным планом и сам скрипт.

## 1. Цель
Скрипт `make_report.py` создаёт .xlsx-файл с двумя листами: «Все задачи» и «План на неделю». Тесты проверяют работу скрипта.

## 2. Входные данные
- Список задач задан в коде константой `TASKS`: кортежи `(id, название, приоритет, срок, выполнено)`.
- Приоритеты: `high` / `normal` / `low`; выполнено: `True` / `False`.
- Источник: захардкоженный список в самом скрипте (в будущем можно вынести в CSV/JSON — вне рамок).
- Дата «сегодня»: фиксированная константа в коде (`2026-10-31`, суббота) — НЕ `date.today()`.

## 3. Выходной файл
- Путь: `FILE_PATH = "/home/monkler/aidd_week_04_mcp/practice/agent/.qwen/skills/report.xlsx"`.
- При каждом запуске файл перезаписывается (детерминированный результат).

## 4. Структура листов
**Лист 1 «Все задачи»**: колонки `ID, Задача, Приоритет, Срок, Статус`.
Все задачи из `TASKS`. Приоритет — русское название (`Высокий`/`Средний`/`Низкий`),
статус — `Выполнено`/`В работе`. Пустой срок → `—`.

**Лист 2 «План на неделю»** — два блока с заголовками:
1. `ПРОСРОЧЕННЫЕ ЗАДАЧИ (до <дата>)`: невыполненные с датой `< сегодня`.
   Сортировка: по просрочке (дни) **по убыванию**, при равенстве — приоритет по возрастанию.
2. `ЗАДАЧИ НА ТЕКУЩЕЙ НЕДЕЛЕ (<пн> – <вс>)`: невыполненные с `сегодня <= срок <= воскресенье текущей недели`.
   Колонка «Дней до срока» = срок − сегодня. Сортировка: по сроку по возрастанию,
   при равенстве — приоритет по возрастанию.

Текущая неделя = понедельник…воскресенье, содержащие дату «сегодня».

## 5. Форматирование
Сетка границ на всех ячейках, жирный белый заголовок с синей заливкой,
заливка по приоритету (high F8CBAD / normal FCE4D6 / low C6EFCE),
заморозка строки заголовка на листе 1, автофильтр, перенос текста,
дата в формате ДД.ММ.ГГГГ, ширины колонок под содержимое.

## 6. Требования к коду
- Зависимости: только `openpyxl` (проверить, что установлен).
- Запуск: `python3 make_report.py`, без аргументов и внешних запросов.
- Логика — в функциях или под `if __name__ == "__main__"`, чтобы импорт модуля ничего не создавал.

## 7. Тесты (`verify_report.py`)
Проверяют и сравниваются **с исходным `TASKS`**, а не с захардкоженным ожиданием:
- имена листов ровно `["Все задачи", "План на неделю"]`;
- лист 1: набор строк = `TASKS` (с учётом русских названий и формата дат);
- лист 2: корректно найдены границы блоков, наборы и значения строк
  (просрочка/дни до срока вычислены так же, как в скрипте), порядок сортировки;
- количество строк.
Запуск: `python3 verify_report.py` — выводит OK и завершается с ошибкой при расхождении.
Сначала должны быть написаны тесты, а потом скрипт, корректность которого определяется прохождением тестов.
Тесты нельзя подгонять под скрипт.
